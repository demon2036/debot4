# Crypto北斗叙事研究语料（69条）

## 结论先行

北斗的核心方法不是“看到KOL买入就机械跟单”，而是先判断：这件事是否真实、这个CA是否真是正确载体、叙事能否一句话说清、为什么会继续传播、当前是否仍在早期，以及什么事实会让判断失效。

KOL、聪明钱包、官方互动和大户地址很重要，但在他的文章中主要扮演三种角色：发现入口、交叉验证、短期催化。它们不能取代叙事，也不能取代价格位置。方法论帖 `2010027891149680767` 甚至明确提醒：市场变化后，过去的聪明钱包也可能归零。

因此，适合交易系统的组合不是“纯KOL跟单”，而是：

1. 用DeBot的真实KOL/SmartMoney买入作为候选准入或发现信号。
2. 用北斗式叙事框架判断该代币是不是当前事件的正确交易载体。
3. 用实时链上数据确认叙事已经开始转化为购买力，但尚未进入拥挤兑现期。
4. 在决定买入的当下重新读取区块、报价、FDV和流动性；历史信号与缓存MC都不能充当成交MC。
5. 记录真实模拟成交后的1小时峰值、回撤和可执行退出，不用作者自报ATH代替PnL。

## 北斗实际在分析什么

### 1. 真实起源

先找真实世界来源：新闻事件、历史文化、原作者、产品、协议、公司或社会冲突。没有真实起源的故事很容易只是临时包装。

例子：Jellybe来自真实动物园事件；114514来自长期存在的东亚互联网梗；HODL来自经典加密文化；GOOSE绑定反恐精英创作者权益故事。

### 2. 正确载体与CA合法性

叙事正确不代表买到的币正确。必须验证原作者认领、creator fee钱包、官方仓库、官方账号、发射平台、合约时间线和竞争CA。

ONE案例是最直接的反例：作者承认第一次发出的CA不是官方CA并道歉。一个系统若跳过“叙事到CA的映射”，分析再漂亮也可能买错币。

### 3. 一句话定位

强叙事需要能被普通人立刻复述，例如：

- MOLT：AI版Reddit。
- SPACE：Crypto版Starlink。
- MILADY：BSC版OpenClaw AI伴侣。
- SOLUNA：被建设者嫌弃、却养活Solana的Meme群体。
- GOOSE：CS创作者权益与反垄断符号。

这不是文案装饰，而是传播压缩率：越容易一句话转述，传播摩擦越低。

### 4. “识别度”与传播发动机

北斗反复使用的核心词是“识别度”。可拆成：视觉或词语是否显眼、是否容易二创、是否跨文化、是否带情绪、是否能形成“我们对他们”的身份冲突，以及是否有连续的新素材。

单纯“有故事”不够。故事必须能从一个账号传给下一群人，并在传递时继续产生新内容。

### 5. 当前催化剂

叙事需要进入当前时间窗口：官方互动、主流媒体、创作者认领、节日、上市、产品发布、协议上线、社会事件或名人提及。

但“关注”“转发”“进群”和“正式认领”必须分级。DOG和ZOE的文章都把未来正式认领列为关键变量，说明互动不能自动当成最终背书。

### 6. 类比与品类龙头

用历史成功项目做类比，寻找相同的传播结构，再明确不同点。类比只能生成假设，不能直接证明上涨。

Jellybe类比MooDeng、Punch和Neiro；LIQUID对比SNOWBALL机制；GORK依赖旧IP记忆和Elon再次提及。若只保留相似点、不记录差异与失效条件，就会变成幸存者偏差。

### 7. 市场确认

叙事要在链上转化为购买力：holder增长、成交额/市值比、换手、回撤承接、成交持续性、筹码变化、社区持续运营和K线结构。

XOGE文章强调holder从三千多到五千、交易量约为市值四倍；114514强调插针后的承接；CLAWDBOX则因交易量极低而被作者降为彩票仓。

### 8. 阶段、位置与失效

北斗自己的原则是“位置大于研判，交易计划大于研判”。同一个好叙事，在潜伏期、点火期、扩散期、拥挤期和崩盘后的赔率完全不同。

每个判断都应配失效条件：错误CA、DEV rug、产品不交付、必须依赖名人连续喊话、获利盘过重、流动性枯竭、竞争CA胜出、创作者停止运营或链上承接消失。

## 对交易系统的直接约束

### 候选准入

用户提出的“KOL历史买过才有意义”可作为强过滤器，但需要限定为可验证的链上买入，而不是关注、点赞、转发或口头提及：

- exact contract address 匹配；
- KOL/钱包身份已归因；
- 历史买入交易、时间和金额可复核；
- 排除只收到空投、项目方转账、自买自卖和同一实体多钱包；
- 记录该KOL历史命中率、峰值前是否真的早、最大回撤和是否常在高位出现。

北斗语料支持把KOL当作候选入口和验证层，不支持把“KOL数量”当唯一买入模型。

### 叙事门

候选至少回答下面五个具体问题，答不出来就不买：

1. 真实发生了什么？给出原始来源和时间线。
2. 为什么这个CA是该事件的正确交易载体？
3. 普通人用一句话怎么转述？
4. 接下来24小时还有谁、什么渠道、什么事件会继续传播？
5. 哪个事实出现时立刻判错？

### 时点门

系统必须区分：潜伏、点火、扩散、拥挤、回撤、事后。出现以下措辞的资料不能作为早期信号：

- “从X到Y”；
- “复盘”；
- “群里早期”；
- “错过大部分涨幅”；
- “已经进入亿级”；
- “目前高了，不追高”。

这些内容可以训练叙事特征，不能倒灌为当时可执行BUY。

### 买入门

DeBot发出当前信号后，真正决定BUY的那一刻才读取：最新可信区块、可执行路由、报价、流动性、税率和FDV。BUY MC必须来自这个执行快照，不能来自30秒前的采集值。

### 退出与研究闭环

只记录“买后1小时最高MC”仍不够判断能否赚钱，还必须同时记录：

- 首次达到1.2x、1.5x、2x所需时间；
- 从峰值到可执行卖出的回撤；
- 以固定仓位卖出时的价格冲击和税费；
- 1分钟、5分钟、15分钟、30分钟、60分钟路径；
- 止损是否先触发，再出现峰值；
- 实际规则下的已实现模拟PnL。

否则，MOLT、WOJAK和LOBSTAR这种案例会让系统看起来“抓到百倍”，但真实策略可能根本拿不到。

## 研究限制

1. 原始归档截止2026-03-04，晚于该日期的走势不在语料中。
2. 许多公开推文晚于私域群讨论，不能用私域低价评价公开跟随者的收益。
3. 推文结果主要是作者自报，没有完整订单、手续费、滑点和卖出记录。
4. 作者更倾向分享值得讲的项目，天然存在选择偏差和幸存者偏差。
5. 官方互动、关注和转发不等于正式代币背书。
6. 本语料用于提炼可检验假设，不能直接证明任何策略未来盈利。
